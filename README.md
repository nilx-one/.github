# nilx.one GitHub configuration

Organization-wide GitHub configuration and public profile for the **nilx.one** namespace.

`nilx.one` is the canonical ecosystem index rooted in `0x0sky`. It contains distinct identities, organizations, and products; **0x1 is a protocol product, not the organization itself.**

This repository contains the public organization profile and may later host shared issue templates, contribution guidance, funding metadata, and other GitHub defaults.

See [`profile/README.md`](profile/README.md) for the public namespace overview.
